# EcoPack — Interactive Sustainable Packaging Network

A React + Vite frontend prototype for sustainable packaging decisions and sourcing.

## Easiest way on Windows

Double-click **`RUN_ECOPACK.bat`**. It opens the project in the correct folder, installs dependencies the first time, and starts Vite.

## Or run manually

```bash
npm install
npm run dev
```

Then open the Vite URL shown in the terminal (normally `http://localhost:5173`).

## New interactive homepage
- Real 3D Earth rendered with Three.js
- Drag to rotate and scroll to zoom
- Slow automatic globe revolution when idle
- Manufacturer, material, and product location markers
- Toggle each marker category on/off
- Click a location to see supplier / material / product availability
- Curved sourcing-route arcs
- Improved EcoPack logo and premium feature cards

## Included pages
- Home / sourcing globe
- AI packaging optimizer
- Logistics comparison
- Material library
- Virtual testing simulator
- Environmental impact dashboard
- Quote estimator
- Statistics
- Reuse & recycle ideas
- Feedback form
- Eco AI assistant drawer

The supplier locations, availability counts, sustainability metrics, and calculations are illustrative demo data for a prototype/presentation and are not live commercial inventory.
